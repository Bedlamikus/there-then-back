====================================================
   СИСТЕМА ВСТРЯСКИ КАМЕРЫ ОТ ВЗРЫВОВ
====================================================

ОПИСАНИЕ:
---------
Система автоматической встряски камеры при взрывах снарядов рядом с игроком.
Использует квадратичное расстояние для оптимизации производительности.
Работает через событийную систему GlobalEvents.

КОМПОНЕНТЫ:
-----------
1. Projectile.cs - проверка расстояния до игрока и вызов события
2. GlobalEvents.cs - событие CameraShake(float intensity)
3. CameraShakeController.cs - обработка встряски камеры

НАСТРОЙКА:
----------
1. Добавьте CameraShakeController на камеру игрока
2. Настройте параметры встряски в инспекторе:
   - Max Shake Intensity: максимальная сила встряски (0.5)
   - Shake Duration: длительность встряски (0.3 сек)
   - Shake Frequency: частота колебаний (20 Гц)
   - Shake Curve: кривая затухания
   - Shake Axes: оси встряски (X, Y, Z)

3. Настройте снаряды для встряски:
   - Откройте префаб снаряда
   - В компоненте Projectile установите:
     - Camera Shake: true

РАБОТА СИСТЕМЫ:
---------------
1. Снаряд взрывается → вызывает Projectile.DoDamage()
2. Если cameraShake = true → вызывается GlobalEvents.CameraShake(explosionPosition)
3. CameraShakeController получает событие с координатами взрыва
4. Вычисляется квадратичное расстояние от взрыва до игрока
5. Если расстояние <= cameraShakeRadius → запускается встряска
6. Камера трясется по заданным параметрам с затуханием

ОПТИМИЗАЦИЯ:
------------
- Используется квадратичное расстояние (sqrMagnitude) вместо обычного
- Экономия на вычислении квадратного корня
- Проверка только при взрыве снаряда (не каждый кадр)
- Ленивое свойство Player - FindObjectOfType вызывается только при первом обращении
- Снаряд не знает о игроке - чистая архитектура

ИНТЕНСИВНОСТЬ ВСТРЯСКИ:
-----------------------
- Максимальная (1.0) в центре взрыва
- Минимальная (0.0) на границе радиуса
- Формула: intensity = 1.0 - (sqrDistance / cameraShakeRadius)
- Ограничивается Mathf.Clamp01()

ПРИМЕР НАСТРОЙКИ:
-----------------
CameraShakeController:
  Max Shake Intensity: 0.5
  Shake Duration: 0.3
  Shake Frequency: 20
  Shake Curve: EaseInOut(0,1,1,0)
  Camera Shake Radius: 100 (10 метров)
  Shake X: true
  Shake Y: true  
  Shake Z: false

Projectile (Dinamit):
  Camera Shake: true

РЕКОМЕНДАЦИИ:
-------------
- Используйте встряску только для мощных снарядов (динамит, ракеты)
- Радиус 10м подходит для большинства случаев
- Интенсивность 0.5 - комфортная для игрока
- Длительность 0.3 сек - не мешает геймплею
- Встряска по X и Y осям - наиболее заметна

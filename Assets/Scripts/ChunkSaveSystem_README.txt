================================================================================
ОПТИМИЗИРОВАННАЯ СИСТЕМА СОХРАНЕНИЯ ЧАНКОВ
================================================================================

ПРОБЛЕМА:
---------
Старая система сохраняла весь мир за раз, что вызывало лаги при автосохранении.

РЕШЕНИЕ:
--------
✅ Каждый чанк сохраняется автономно
✅ Постепенная генерация/загрузка мира (1-5 кадров на чанк)
✅ Автосохранение только измененных чанков
✅ Первый запуск определяется флагом в PlayerPrefs
✅ Минимальные лаги при работе


================================================================================
КАК ЭТО РАБОТАЕТ
================================================================================

1. ПЕРВЫЙ ЗАПУСК ИГРЫ
   ---------------------
   - Проверяется флаг "isFirstRun" в GameSettings
   - Генерируется мир постепенно (по 1 чанку за 1-5 кадров)
   - Флаг устанавливается в false
   - Результат: плавная генерация без лагов

2. ПОСЛЕДУЮЩИЕ ЗАПУСКИ
   --------------------
   - Загружаются сохраненные чанки из PlayerPrefs
   - Чанки создаются постепенно (по 1 за 1-5 кадров)
   - Если чанк не сохранен - генерируется новый
   - Результат: плавная загрузка сохраненного мира

3. АВТОСОХРАНЕНИЕ ЧАНКОВ
   ----------------------
   - Каждый чанк отслеживает свои изменения (isDirty флаг)
   - Каждые 5 секунд чанк проверяет наличие изменений
   - Сохраняется только если были изменения
   - Результат: микро-лаги вместо больших фризов


================================================================================
НАСТРОЙКИ В ИНСПЕКТОРЕ
================================================================================

VoxelWorld:
-----------
[Generation Settings]
  ✓ Use Progressive Generation - постепенная генерация/загрузка
  ✓ Min Frames Per Chunk       - минимум кадров на создание чанка (1)
  ✓ Max Frames Per Chunk       - максимум кадров на создание чанка (5)

VoxelChunk16:
-------------
Автоматически:
  ✓ Каждые 5 секунд проверяет изменения
  ✓ Сохраняется при уничтожении (OnDestroy)
  ✓ Сохраняется с именем: "Chunk_{x}_{z}"


================================================================================
ИЗМЕНЕНИЯ В БЛОКАХ → АВТОСОХРАНЕНИЕ
================================================================================

Когда блок изменяется:
  DamageSphere()  → builder.MarkDirty()
  DamageBlock()   → builder.MarkDirty()
  SetBlock()      → builder.MarkDirty()
  Build()         → builder.MarkDirty()
        ↓
  Через 5 секунд → builder.SaveChunk()
        ↓
  Сохранение в PlayerPrefs: "SaveData_Chunk_{x}_{z}"


================================================================================
CONTEXT MENU КОМАНДЫ
================================================================================

На компоненте VoxelWorld (правый клик):

1. "Generate world"
   - Мгновенная генерация (без задержек)
   - Для отладки

2. "Force Save All Chunks"
   - Принудительно сохранить ВСЕ чанки сейчас
   - Полезно перед выходом из редактора

3. "Delete All Saves (Reset to First Run)"
   - Удалить все сохранения
   - Сбросить флаг первого запуска
   - Следующий запуск будет как первый

4. "Reset World"
   - Удалить сохранения + перегенерировать мир


================================================================================
СТРУКТУРА ДАННЫХ
================================================================================

GameSettingsData:
-----------------
  - isFirstRun: bool          - флаг первого запуска
  - firstRunTimestamp: long   - время первого запуска
  - worldChunksX/Z: int       - размеры мира

SingleChunkData:
----------------
  - cx, cz: int               - координаты чанка
  - blockData: int[]          - плоский массив блоков
  - hpData: short[]           - плоский массив HP
  - lastModified: long        - время изменения


================================================================================
КЛЮЧИ В PLAYERPREFS
================================================================================

- "SaveData_GameSettings"      - глобальные настройки игры
- "SaveData_Chunk_{x}_{z}"     - данные каждого чанка
  Например:
  - "SaveData_Chunk_0_0"
  - "SaveData_Chunk_0_1"
  - "SaveData_Chunk_1_0"
  - и т.д.


================================================================================
ПРОИЗВОДИТЕЛЬНОСТЬ
================================================================================

ДО (старая система):
  ❌ Сохранение всего мира: 500-1000мс фриз
  ❌ Автосохранение каждые 30 сек = заметные лаги
  ❌ При выходе большой фриз

ПОСЛЕ (новая система):
  ✅ Сохранение 1 чанка: ~5-10мс
  ✅ Автосохранение только измененных: незаметно
  ✅ Постепенная генерация: 60 FPS даже при загрузке
  ✅ При выходе: только измененные чанки


================================================================================
ЧТО СОХРАНЯЕТСЯ
================================================================================

✅ Все блоки в чанке (тип блока)
✅ HP каждого блока
✅ Координаты чанка
✅ Время последнего изменения

❌ НЕ сохраняется:
  - Позиция игрока (пока, можно добавить отдельно)
  - Инвентарь (добавляется отдельно через SaveData<T>)
  - Настройки (добавляются отдельно)


================================================================================
КАК ДОБАВИТЬ СОХРАНЕНИЕ ДЛЯ СВОЕЙ СУЩНОСТИ
================================================================================

Пример:
-------
[System.Serializable]
public class MyEntityData
{
    public float x, y, z;
    public int health;
    public MyEntityData() { }
}

public class MyEntity : MonoBehaviour
{
    private SaveData<MyEntityData> saveData;
    
    void Start()
    {
        saveData = new SaveData<MyEntityData>(gameObject.name);
        if (saveData.Exists())
        {
            var data = saveData.Load();
            transform.position = new Vector3(data.x, data.y, data.z);
        }
    }
    
    void OnDestroy()
    {
        var data = saveData.Data;
        data.x = transform.position.x;
        data.y = transform.position.y;
        data.z = transform.position.z;
        saveData.Save();
    }
}


================================================================================
ОТЛАДКА
================================================================================

В консоли Unity будут логи:
  - "VoxelWorld: Первый запуск игры..."
  - "VoxelWorld: Загружаем мир из сохранений"
  - "VoxelWorld: Постепенная генерация завершена"
  - "VoxelWorld: Загрузка завершена (загружено: X, создано: Y)"

Для принудительного сохранения всех чанков:
  VoxelWorld.Instance.ForceSaveAllChunks();

Для сброса игры в первый запуск:
  VoxelWorld.Instance.DeleteAllSaves();


================================================================================
ПРИМЕЧАНИЯ
================================================================================

1. Каждый чанк занимает ~8-12KB в JSON (зависит от содержимого)
2. Мир 5x5 = 25 чанков = ~200-300KB в PlayerPrefs (приемлемо)
3. PlayerPrefs имеет лимит ~1MB, но можно расширить
4. Для больших миров рекомендуется переход на файловую систему

5. Постепенная загрузка обеспечивает 60 FPS даже при загрузке 100+ чанков
6. Автосохранение незаметно, т.к. сохраняет по 1-2 чанка за раз
